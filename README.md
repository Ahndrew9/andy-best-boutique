🛍️ Andy Best Boutique

A full-stack e-commerce web application featuring a customer-facing storefront and a secure administrative dashboard, built with Node.js, Express.js, PostgreSQL (Supabase), and Cloudinary.

Live Demo & Access
Storefront Live URL: [https://andy-best-boutique.onrender.com](https://andy-best-boutique.onrender.com) 
Admin Dashboard: `https://andy-best-boutique.onrender.com/admin`
Default Admin Password: *****

Tech Stack
Backend: Node.js, Express.js
Database: PostgreSQL (Hosted on Supabase via connection pool)
Image Management: Cloudinary API & Multer (for temporary file uploads)
Frontend: HTML5, CSS3, JavaScript (Vanilla)
Hosting / Deployment: Render


Features
Dynamic Product Catalog: Fetches and displays products stored in the cloud PostgreSQL database.
Admin Dashboard Management:
  * Secure password-protected login.
  * Add new products with image uploads directly to Cloudinary.
  * Delete existing inventory items.
  * View, update status, and manage customer orders.
  * Shopping Cart & Checkout Flow: Seamless local shopping cart functionality with simulated cloud order submission.
